# 🧬 CellHunter

**AI-приложение для автоматического обнаружения и подсчёта клеток на микроскопических изображениях.**

CellHunter использует нейросеть CellPose для детекции ядер клеток, обрабатывает папки с изображениями и выгружает результаты в Excel.

---

## 📦 Что входит

- **CellPose** — нейросеть для детекции ядер клеток
- **YOLO** — альтернативная модель для общих объектов
- **GPU ускорение** (CUDA) — если есть NVIDIA видеокарта
- **Экспорт в Excel** — отчет с количеством клеток по каждому изображению
- **Интерфейс WPF** — понятный и удобный

---

## ⚡ Требования

- **Windows 10/11** (64-bit)
- **~5 ГБ свободного места** (для Python + библиотек)
- **NVIDIA GPU** (опционально, но ускоряет в 50-100 раз)

---

## 🚀 Установка (всё в одной папке, ничего не засоряет систему)

1. **Скачайте** архив `CellHunter_Release_v1.0.zip`
2. **Распакуйте** в любую папку (например, `C:\CellHunter`)
3. **Запустите** `setup.bat` и подождите 3-5 минут
   - Батник сам скачает Python, установит зависимости и создаст ярлык
4. **Запускайте** через ярлык на рабочем столе **CellHunter**

---

## 🖥️ Как пользоваться

1. Нажмите **"Выбрать папку"** и укажите папку с изображениями
   - Поддерживаются форматы: `.tif`, `.tiff`, `.png`, `.jpg`, `.jpeg`, `.bmp`
2. Выберите модель:
   - **CellPose** (рекомендуется для ядер клеток)
   - **YOLO** (для общих объектов)
3. Нажмите **"Запуск"** и дождитесь завершения
4. Посмотрите результаты в таблице:
   - Имя файла, количество ядер, размеры, время обработки
5. Нажмите **"Excel"** для сохранения отчета в папку с изображениями

## 🗑️ Удаление

Чтобы полностью удалить CellHunter:
1. Удалите ярлык с рабочего стола
2. Удалите папку, куда распаковывали архив

Либо запустите uninstall.bat.

**Всё!** Никаких записей в реестре или системных папках.

---

## ❓ Частые вопросы

**Что делать, если при запуске ошибка "Python не найден"?**
Запустите `setup.bat` ещё раз.

**Почему медленно работает?**
Используйте GPU. Если его нет — будет работать на CPU (~30-50 сек на изображение).

**Можно ли обработать 1000 изображений?**
Да. Приложение обрабатывает все изображения в папке.

**Какая точность?**
На тестовых данных BBBC001 точность 10-20% от ручного подсчёта.
